# Application Layout - User Interface Organization

## Overview

The Observer Frontend provides different interfaces based on whether you're logged in or using the public dashboard.

## User Interface Types

### For Logged-In Users
When you're logged in, you'll see:
- Full navigation menu
- Sidebar with quick access to features
- Your profile information
- Complete dashboard controls
- Logout option

### For Public Access
If you're not logged in, you'll have:
- Basic navigation
- Access to public patient data
- Option to log in for full features

## How It Works

The application automatically shows you the right interface based on your login status. If you log in or out, the interface updates immediately to match your access level.

## Current Status

The Observer Frontend currently operates primarily in public mode, allowing anyone to view healthcare data visualizations and analysis.
